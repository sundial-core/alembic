# Transparency

## Order of operations

1. Constants written into public source code.
2. Source published.
3. Block zero mined. Zero coins existed before it.
4. Every subsequent coin comes from a block reward, paid in full to the miner.

## What does not exist

- No dev fee.
- No treasury address.
- No premine, no allocation, no unlock calendar.
- No governance parameter left adjustable after launch.

## What you can check

- Source code: https://github.com/alembic-core/alembic
- Release checksums: published on the downloads page.
- Explorer: https://alembic-core.github.io/alembic/explorer/

If any statement here disagrees with the chain, the chain wins.
